## ส่วนที่ 4: ทดสอบโมเดลทำนายด้วยรูปภาพวาดมือภายนอก (45 นาที)

เพื่อแสดงการทำงานของ Inference Pipeline ผู้เรียนจะนำภาพที่วาดขึ้นภายนอกมาโหลดแปลงรูปแบบด้วย OpenCV และนำส่งพยากรณ์ผ่านโมเดล PyTorch

### ขั้นตอนที่ 4.1: เตรียมไฟล์รูปภาพ
1. เปิดโปรแกรม **Microsoft Paint** หรือเครื่องมือตกแต่งรูปภาพอื่นๆ ในเครื่องคอมพิวเตอร์
2. ปรับขนาด Canvas ของภาพให้มีขนาด **$280 \times 280$ พิกเซล** (หรือสัดส่วนสี่เหลี่ยมจัตุรัสขนาดเล็ก)
3. ทาสีฉากหลังให้เป็น **สีดำสนิท (สีค่า 0)**
4. เลือกพู่กันหรือดินสอวาดสีเขียนเส้น **สีขาวบริสุทธิ์ (สีค่า 255)** เขียนตัวเลขลายมือตนเองเพียงตัวเดียว (เช่น เลข 3 หรือ เลข 7) ลงไปตรงกลางรูปภาพ
5. บันทึกรูปภาพไว้ในรากโฟลเดอร์โปรเจกต์ ตั้งชื่อว่า `digit.png`

> [!WARNING]
> แนะนำหลีกเลี่ยงกระดาษขาวดินสอดำหรือการลืมกลับสีรูปภาพ เพราะโมเดล MNIST ถูกพัฒนามาให้อ่านข้อมูลรูปภาพเฉพาะเลขสีขาวบนพื้นหลังดำสนิทเท่านั้น! หากส่งภาพกลับสีกัน จะทำให้โมเดลได้ความมั่นใจผิดพลาดทันที

### ขั้นตอนที่ 4.2: รันโค้ดทำนายรูปภาพ
1. สร้างไฟล์ชื่อ [infer_mnist.py](file:///c:/Users/Newsk/Downloads/imageprocessing/infer_mnist.py) และเขียนโค้ดตาม [week9_code_guide.md](file:///c:/Users/Newsk/Downloads/imageprocessing/week9_code_guide.md#L221-L297) ลงไป
2. พิมพ์รันโมเดลทดสอบ:
   ```bash
   python infer_mnist.py
   ```
3. ตรวจเช็กหน้าต่างป๊อปอัป OpenCV และหน้าต่าง Terminal ว่าคลาสคำทำนายสรุปเปรียบเทียบกับค่าจริงที่คุณเขียนเขียนตัวเลขลงไปตรงกันหรือไม่

## ส่วนที่ 5: แบบฝึกหัดท้าทายประจำสัปดาห์ (Challenge) (30 นาที)

เพื่อแสดงความเข้าใจในการจัดการข้อมูลและการเทรน นักศึกษาจะต้องเลือกทำแบบฝึกหัดเพิ่มคะแนนอย่างน้อยหนึ่งข้อ:

1. **โจทย์ท้าทายการสกัดและจัดการข้อมูล (Data Split & Preprocess Challenge):**
   * เขียนโปรแกรมด้วย Python สุ่มแบ่งรูปภาพจริง (เช่น รูปปั้นในแล็บ หรือรูปดอกไม้/ผลไม้) ด้วยตนเองโดย **ห้ามใช้ scikit-learn** (ห้ามนำเข้า `train_test_split`) 
   * คำใบ้: ใช้ฟังก์ชัน `numpy.random.permutation` หรือการสร้างชุดข้อมูลโดยสุ่มตัวชี้วัดดัชนี (Index) อิงสัดส่วน 80:20
2. **โจทย์ท้าทายทำนายผลสดเรียลไทม์ (Webcam Inference Challenge):**
   * ปรับแต่งสคริปต์ `infer_mnist.py` เพื่ออ่านข้อมูลวิดีโอสดผ่านกล้องหน้าเครื่องคอมพิวเตอร์
   * ทำกรอบสี่เหลี่ยมตรวจจับตรงกลางกล้อง เพื่อให้ระบบครอปตัดขนาด ปรับสเกลช่วงพิกเซล และส่งเข้าทำนายผลลัพธ์สดแบบเฟรมต่อเฟรม พร้อมเขียนแสดงค่าตัวเลขบนแถบหน้าต่างวิดีโอ
