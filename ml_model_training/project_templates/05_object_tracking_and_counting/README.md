# 🚦 Template โปรเจกต์ที่ 5: การติดตามวัตถุและระบบนับจำนวนข้ามเส้น (Multi-Object Tracking & Line-Crossing Counter)

ยินดีต้อนรับสู่ Template สำหรับทำโปรเจกต์ **Multi-Object Tracking (MOT) & Line-Crossing Counter (การติดตามวัตถุและนับจำนวนข้ามเส้นตรวจจับ)** เหมาะสำหรับงานวิเคราะห์วิดีโอ (Video Analytics), นับคนเข้าออกอาคาร, และตรวจวัดความหนาแน่นของการจราจร

---

## 💡 ไอเดียหัวข้อโปรเจกต์ที่นักศึกษาสามารถนำไปทำได้
* 🛍️ **ระบบนับจำนวนคนเดินเข้า-ออกร้านค้า (Retail Store Footfall Counter):** นับจำนวนคนเดินเข้า (In) และเดินออก (Out) พร้อมคำนวณจำนวนคนคงเหลือในร้าน
* 🛣️ **ระบบนับจำนวนและแยกประเภทยานพาหนะบนทางด่วน (Highway Vehicle Flow Counter):** นับรถเก๋ง, รถบรรทุก, มอเตอร์ไซค์ พร้อมคำนวณอัตราความเร็วเฉลี่ย
* 🐄 **ระบบนับจำนวนสัตว์ในฟาร์มอัจฉริยะ (Smart Farm Livestock Counter):** นับวัวหรือแกะที่เดินผ่านประตูโรงเรือน
* 📦 **ระบบนับสินค้าบนสายพานลำเลียง (Conveyor Belt Inventory Counter):** นับชิ้นงานอัตโนมัติแบบไม่นับซ้ำ

## 🧠 หลักการทำงานของ Multi-Object Tracking (ByteTrack / BoT-SORT)

```
 Frame t=1                     Frame t=2                     Frame t=3
┌───────────────────────┐     ┌───────────────────────┐     ┌───────────────────────┐
│  🚗 [ID: 1]           │     │       🚗 [ID: 1]      │     │             🚗 [ID: 1]│
│  (x: 100, y: 200)     │ ──► │       (x: 150, y: 200)│ ──► │             (x: 200)  │
└───────────────────────┘     └───────────────────────┘     └───────────────────────┘
                                Kalman Filter พยากรณ์
                                และจับคู่พิกัดต่อเนื่อง
```

* อัลกอริทึม **ByteTrack** จะกำหนด **Tracking ID** คงที่ให้กับวัตถุแต่ละชิ้น แม้วัตถุจะเคลื่อนที่ไปในเฟรมถัดไป หรือถูกสิ่งกีดขวางบังชั่วคราว (Occlusion)

## 📐 คณิตศาสตร์การตรวจจับการข้ามเส้น (Line-Crossing Collision Math)

กำหนดเส้นตรวจจับเสมือน $L$ จากจุด $P_1(x_1, y_1)$ ไปยัง $P_2(x_2, y_2)$ และเวกเตอร์การเคลื่อนที่ของวัตถุจากตำแหน่งเฟรมก่อนหน้า $C_{\text{prev}}$ ไปยังตำแหน่งปัจจุบัน $C_{\text{curr}}$:

```
                      P1 (จุดเริ่มต้นเส้น)
                      │
   C_prev ─────────── ┼ ───────────► C_curr (ตัดผ่านเส้น = นับ +1)
   (เฟรมก่อนหน้า)       │               (เฟรมปัจจุบัน)
                      P2 (จุดสิ้นสุดเส้น)
```

$$\text{Line Cross Condition:} \quad (\vec{P_1P_2} \times \vec{P_1C_{\text{prev}}}) \cdot (\vec{P_1P_2} \times \vec{P_1C_{\text{curr}}}) < 0$$

เมื่อทิศทาง Cross Product มีเครื่องหมายตรงข้ามกัน แสดงว่าวัตถุได้ **เคลื่อนที่ตัดผ่านเส้นตรวจจับเรียบร้อยแล้ว**
